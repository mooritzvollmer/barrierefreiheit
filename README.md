# Barrierefreiheit im Web

Eine kompakte, verständliche Einführung in digitale Barrierefreiheit mit praktischen Zugängen zu WCAG, Kontrasten, Tastaturbedienung und zugänglichen Inhalten.

**Live:** [barrierefreiheit.moritzvollmer.de](https://barrierefreiheit.moritzvollmer.de/)

## Schwerpunkte

- verständliche Einordnung zentraler Anforderungen
- semantisch strukturierte und tastaturbedienbare Oberfläche
- Verweise auf weiterführende Prüfwerkzeuge
- technische SEO- und Accessibility-Metadaten

## Technische Basis

Statisches HTML, JavaScript, SCSS und Vite.

```sh
npm install
npm run dev
npm run build
```
